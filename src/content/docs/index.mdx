## Um espaço de estudo contínuo

O **Graciosa Ovelha** é uma biblioteca de estudos da Torah organizada para acompanhar tanto a leitura diária dos capítulos quanto o ciclo semanal das parashot.

O projeto foi concebido para reunir textos de estudo e reflexão sob a perspectiva da **Cabalá autêntica**, mantendo uma estrutura simples para consulta, continuidade e aprofundamento.

## Como o conteúdo está organizado

- **Torah:** estudos organizados pelos cinco livros e seus capítulos.
- **Parashot:** análises das porções semanais, também agrupadas pelo livro correspondente.

## Ritmo de publicação

Os estudos são adicionados gradualmente à biblioteca, sem calendário fixo de publicação.
